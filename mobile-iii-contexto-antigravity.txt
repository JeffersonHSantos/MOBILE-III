RESOLUÇÃO E DIAGNÓSTICO PELO ANTIGRAVITY (23/11/2026)
============================================================

1. CAUSA RAIZ IDENTIFICADA:
   - No retorno do fluxo OAuth ou ao mapear o usuário social no AuthService._toUserMap, era chamado DbHelper.upsertSocialUser.
   - O sqflite nativo não possui implementação Web pronta e invocava getDatabasesPath(), gerando MissingPluginException / UnsupportedError no Web.
   - Essa falha interrompia silenciosamente o getRedirectResult() (capturado em catch genérico retornando null) e quebrava o stream authenticatedUserChanges.
   - Além disso, signInWithRedirect retornava null imediatamente antes do navegador descarregar a página, acionando a mensagem de erro antes do redirecionamento.
   - No getRedirectResult(), quando a sessão era restaurada pelo Firebase JS SDK antes de ler a credencial, FirebaseAuth.instance.currentUser já continha o usuário mas não era reaproveitado como fallback.

2. AÇÕES E CORREÇÕES IMPLEMENTADAS:
   a) DbHelper Multiplataforma (lib/database/db_helper.dart):
      - Implementado suporte a ambiente Web via armazenamento em memória para usuários, mantendo sqflite nativo para Android/iOS/Desktop.
      - upsertSocialUser, login e registerUser agora funcionam sem exceções tanto no Web quanto no Android.
   b) AuthService Robusto (lib/services/auth_service.dart):
      - Web: Implementado signInWithPopup como fluxo primário (mais rápido e sem perda de estado/recarregamento) e fallback automático para signInWithRedirect caso o popup seja bloqueado pelo navegador.
      - getWebRedirectResult(): Agora recupera tanto o retorno do redirect quanto FirebaseAuth.instance.currentUser como fallback resiliente.
      - _toUserMap(): O sincronismo com banco local agora é protegido por try/catch para que problemas de I/O local nunca abortem a autenticação social do usuário.
      - Implementado método signOut() para permitir logout seguro de qualquer provedor.
      - Log detalhado de erros com FirebaseAuthException.code e message para total rastreabilidade.
   c) Interface e Navegação (lib/features/auth/screens/login_screen.dart & lib/features/home/screens/home_screen.dart):
      - login_screen agora distingue redirecionamento em andamento de falha real, evitando avisos falsos de erro.
      - Mensagens de erro são despachadas com addPostFrameCallback para evitar conflito de montagem de widget.
      - home_screen ganhou botão de Logout (Sair da conta) no AppBar, reconduzindo à LoginScreen.
   d) Análise e Testes:
      - analysis_options.yaml configurado; `flutter analyze` finalizado com 0 alertas (No issues found!).
      - widget_test.dart atualizado para o app real.
      - home_screen_test.dart adicionado cobrindo renderização e logout.
      - auth_service_test.dart ampliado com testes de banco social e signOut.
      - Suíte completa de 8 testes aprovada: `All tests passed!`.
      - Build de release Web validado com sucesso: `flutter build web --release`.
